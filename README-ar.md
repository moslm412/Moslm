# موقع Mini touch للمفروشات

موقع عربي (من اليمين لليسار) لبيع الأثاث، بدون تسجيل دخول. الطلب عبر واتس اب.

## التشغيل
ارفع كل الملفات في نفس المجلد على أي استضافة (Vercel أو Netlify أو GitHub Pages) وافتح `index.html`.

## الملفات
- `index.html`: هيكل الصفحة.
- `styles.css`: التصميم وألوان الخشب (المتغير `--purple` هو لون الخشب الغامق).
- `products.js`: **أهم ملف للتعديل**: الشعار، رقم واتس اب، رمز QR، شرائح البانر، المنتجات.
- `images.js`: صور المنتجات الحقيقية (مدمجة، لا تحتاج تعديل).
- `app.js`: منطق الموقع (السلة، البحث، الرسم، مولّد QR).
- `firebase-*.js`: اختياري لحفظ الطلبات.

## كلمات البحث للتعديل (Ctrl+F)
| ما تريد تغييره | الملف | كلمة البحث |
|---|---|---|
| صورة الشعار (Mini touch) | products.js | `LOGO_IMAGE` |
| رقم الواتس اب | products.js | `whatsapp:` |
| رمز QR | products.js | `qrUrl` أو `qrImage` |
| رقم الدعم الفني | products.js | `supportPhone` |
| الأثاث في البانر | products.js | `HERO_SLIDES` |
| المنتجات والأسعار | products.js | `window.PRODUCTS` |
| ألوان الخشب | styles.css | `--purple` وكلمة `#a8743f` |

## رمز QR
- إذا تُرك `qrUrl` و`qrImage` فارغين يُولَّد الرمز تلقائياً من عنوان موقعك (لا تحتاج تغييره عند تغيير الدومين).
- لرابط محدد اكتبه في `qrUrl`. ولصورة QR جاهزة ضعها في `qrImage`.

## صور الأثاث الحقيقية
كل منتج يرسم أثاثاً تلقائياً حسب `type`. لاستخدام صورة حقيقية ضع مسارها في `image` للمنتج، أو في `heroImage` للبانر.

## تغيير صورة منتج
صور المنتجات في `images.js` بأسماء مثل `sofaCream`. وفي `products.js` كل منتج يأخذ صورته عبر `image: IMG.sofaCream`. لإضافة صورة جديدة حوّلها إلى base64 وأضفها في `images.js` باسم جديد، ثم اكتب اسمها في المنتج.
